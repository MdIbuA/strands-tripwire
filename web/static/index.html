How Tripwire decides

ContextQuarantine · after every read

Each paragraph the agent reads is scored: "Is any part of this written to an AI, instead of to the human reader?" At 0.5 or above it is removed before the LLM sees it.

ProvenanceGuard · before every send or share

Decider sees only what the user typed plus the proposed action: "Is this something the user asked for?" Below 0.2: deny. 0.2 to 0.6: ask a human. 0.6 and above: proceed.
